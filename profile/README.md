## Overview
DJI Fly for Windows is DJI's app for flying a compatible drone, watching a live camera feed, and keeping an eye on flight telemetry from one screen. It's built for pilots who want quick access to camera view, flight settings, and footage in a single place.

## Features
* Live HD camera feed from the connected drone
* On-screen flight controls and telemetry
* Map-based route planning
* Quick footage editing tools

## FAQ
**Is DJI Fly the same as the older DJI GO Fly app?** No — DJI Fly is a separate, newer app built for DJI's more recent drone models, while the DJI GO Fly app targets older models; check which one your drone requires. **Is DJI Fly free?** Yes, it's free to download, though a compatible DJI drone is required separately. **Which versions of Windows are supported?** Recent 64-bit versions of Windows are supported.
